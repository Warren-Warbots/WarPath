# WarPath

A VS Code extension to visualize and edit WPILib Pose2d arrays and individual variables directly on an FRC field map.
<img width="1836" height="562" alt="image" src="https://github.com/user-attachments/assets/38175b48-3570-43ad-8951-ce57f7dca914" />

## Features

- **Live Preview:** Robots move as you type in your Java code.
- **Interactive Editing:** Drag and rotate robots on the field to update your code instantly.
- **Multi-Array View:** See all your paths at once with unique colors and labels.
- **Isolated Mode:** Click "View [Variable]" to focus on a single path.
- **Panning & Zooming:** Navigate the 2026 FRC field map with ease.

## Usage

1. Open a Java file containing `Pose2d` arrays or variables.
2. Click the CodeLens link **"View All Poses in WarPath"** at the top of the file, or the individual links above each variable.
3. Drag the robot box to move it, or the white handle to rotate it.

## Calibration

The visualizer is calibrated for the 2026 FRC field image (16.54m x 8.21m).
